스케줄러 테스트 프로젝트

스케줄러가 실행 중입니다!

이 애플리케이션이 시작되면 자동으로 스케줄러가 등록됩니다.

  • 첫 실행: 애플리케이션 시작 후 10초 후
  • 반복 주기: 60초마다
  • 실행 내용: 데이터베이스 작업 + API 호출 시뮬레이션

⚠로그 확인 방법

스케줄러의 실행 로그는 서버 콘솔에서 확인할 수 있습니다.

  • IntelliJ IDEA: Run 탭의 콘솔 창
  • Eclipse: Console 창
  • Tomcat 직접 실행: catalina.out 파일

테스트 방법

  1. 자동 실행 확인: 서버 콘솔을 보면서 10초 후 첫 실행을 확인하세요.
  2. 수동 실행: 아래 버튼을 클릭하여 즉시 실행할 수 있습니다.
  3. 반복 확인: 60초마다 자동으로 실행되는 것을 확인하세요.

참고 사항

  • 이 프로젝트는 SP 호출 없이 로그만 출력하는 테스트용입니다.
  • 실제 프로젝트에서는 데이터베이스 연결과 SP 호출 코드를 추가해야 합니다.
  • 실제 운영시에는 SchedulerContextListener.java에서
    실행 주기를 매일 9시로 변경하세요.
